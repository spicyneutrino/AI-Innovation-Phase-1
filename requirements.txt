# SoS Regulatory Crawler — Python dependencies
#
# This repo’s Python project + lockfile live at the repository ROOT (../pyproject.toml).
# Use ONE of the following:
#
# From repo root (AI-Innovation-Phase-1/):
#   uv sync
#   uv add -r automated-data-collection/requirements.txt
#   uv run playwright install chromium
#
# From this directory (automated-data-collection/):
#   uv add --project .. -r requirements.txt
#   uv run --project .. playwright install chromium
#
# If you see: VIRTUAL_ENV=... does not match the project environment path .../.venv
#   Your shell activated automated-data-collection/.venv but uv uses the root .venv.
#   Fix: deactivate; then cd to repo root and run: uv sync
#   Or use the active venv on purpose: uv run --active playwright install chromium
#
# Helper (works from any cwd):
#   bash automated-data-collection/scripts/uv_repo.sh add -r automated-data-collection/requirements.txt
#   bash automated-data-collection/scripts/uv_repo.sh run playwright install chromium
#
# Legacy pip (not recommended if you use uv):
#   pip install -r requirements.txt
#   playwright install chromium
