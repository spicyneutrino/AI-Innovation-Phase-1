# Changelog

- Multi-state regulatory crawler for AL, AR, GA, LA, MS, TN, and TX (dental, medical licensure, real estate agencies).

- Documentation aligned with the Mississippi AI Innovation Hub GitHub Repository Guide (architecture, setup, data notes, limitations, testing).
- Repository hygiene: MIT license, `.env.example`, and deny-all markdown policy with README/docs exceptions.
